# 🏋️ FitLife

O aplicație full-stack pentru managementul activităților de fitness, compusă dintr-un backend Java și un frontend Angular.

---

## 📁 Structura proiectului

```
FitLife/
├── fitnessApplication/   # Backend – Java (Spring Boot)
├── fitnessWeb/           # Frontend – Angular (TypeScript)
└── package-lock.json
```

---

## 🛠️ Tehnologii utilizate

| Layer     | Tehnologie                          |
|-----------|--------------------------------------|
| Backend   | Java · Spring Boot                   |
| Frontend  | Angular · TypeScript · HTML · SCSS   |
| Build     | npm                                  |

---

## ⚙️ Instalare și rulare

### Cerințe prealabile

- Java 17+
- Node.js 18+ și npm
- Angular CLI (`npm install -g @angular/cli`)

---

### Backend (`fitnessApplication`)

```bash
cd fitnessApplication
.\mvnw.cmd spring-boot:run 
```

Serverul pornește implicit pe `http://localhost:8080`.

---

### Frontend (`fitnessWeb`)

```bash
cd fitnessWeb
npm install
npm start
```

Aplicația este disponibilă la `http://localhost:4200`.

---

## ✨ Funcționalități

- Autentificare și înregistrare utilizatori
- Gestionare antrenamente și planuri de fitness
- Interfață web responsivă
